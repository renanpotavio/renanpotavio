## 🧭 Como eu penso produto

1. **Problema antes de solução:** entender quem sofre e por quê
2. **Evidência antes de opinião:** hipóteses testáveis e perguntas bem feitas
3. **Priorização com critério:** decidir o que fazer e o que *não* fazer
4. **Métrica de sucesso desde o início:** saber como medir se funcionou
